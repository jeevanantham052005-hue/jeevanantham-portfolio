# Jeevanantham — Personal Portfolio Website

A modern, premium, dark-themed, highly animated, and fully responsive personal portfolio website for **Jeevanantham**, student developer, web designer, digital marketer, and AI prompt engineer.

## Architecture (3 Core Files)

The project is packaged into a clean, well-commented 3-file setup:

```
jeevanantham-portfolio/
├── index.html              # Complete Semantic HTML5 Document
├── style.css               # Merged CSS (Design Tokens, Glassmorphism, Layouts & Keyframe Animations)
├── script.js               # Merged JavaScript (Particles, Cursor, Navigation, Modals, Form Validation & Toasts)
└── assets/
    ├── resume.html         # Formatted printable / PDF student resume
    └── images/             # Vector icons & preview mockups (SVGs)
```

14. **Education Animated Vertical Timeline**
15. **Contact Section, Form Controls & Copy Buttons**

18. **Footer & Back-to-Top Button**
